# Spec Core v1 — Anclora Azure Bay Landing

## Arquitectura

- Next.js App Router.
- Componentización por secciones.
- Tailwind + utilidades de diseño.

## Reglas técnicas core

- Hero y navegación son ruta crítica de carga.
- Scripts de terceros deben ser diferidos o condicionales.
- Toda modificación de UI crítica requiere revalidación Lighthouse.
