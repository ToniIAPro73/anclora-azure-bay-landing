# SKILL: Accessibility and SEO Guardrails

## Cuándo usar

- Cambios de UI, componentes interactivos, texto visible y estructura semántica.

## Objetivo

Mantener `Accessibility` y `SEO` en 100 sin comprometer diseño premium.

## Checklist

1. Verificar accessible names en botones/enlaces con texto visible.
2. Revisar contraste de CTAs y textos funcionales.
3. Mantener orden de headings.
4. Revisar labels/aria en controles custom.
5. Validar metadata/canonical/og tags.
6. Ejecutar checks y Lighthouse.

## Gate

- Cualquier `label-content-name-mismatch` o `color-contrast` abierto => NO-GO.
