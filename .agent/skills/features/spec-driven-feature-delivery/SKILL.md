# SKILL: Spec-Driven Feature Delivery

## Flujo

1. Crear `sdd/features/<feature>/spec-<feature>-v1.md`.
2. Definir alcance, NFRs y criterios de aceptación.
3. Implementar por iteraciones pequeñas.
4. Ejecutar verificación técnica (`lint`, `test`, `build`).
5. Ejecutar QA funcional + Lighthouse si aplica.
6. Completar gate final y actualizar índice de features.

## Regla

Sin spec y test plan no se cierra la feature.
