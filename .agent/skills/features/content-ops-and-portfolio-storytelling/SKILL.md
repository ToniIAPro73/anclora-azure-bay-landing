# SKILL: Content Ops and Portfolio Storytelling

## Cuándo usar

- Cuando una feature requiera convertir trabajo técnico en mensajes comerciales reutilizables.

## Objetivo

Unificar narrativa de portfolio para web, LinkedIn, social y cold email, sin perder precisión técnica.

## Checklist

1. Definir narrativa en 3 capas: contexto, método, resultado.
2. Crear piezas reutilizables por canal.
3. Mantener coherencia ES/EN.
4. Verificar que el contenido no degrada performance ni a11y.
5. Actualizar SDD y gate final.
