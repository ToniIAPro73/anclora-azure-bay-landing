# Feature Delivery Baseline

Usa este baseline en cualquier prompt de implementación:

1. Resume alcance y riesgos.
2. Identifica impacto en UI crítica (hero/nav).
3. Define plan técnico en pasos verificables.
4. Implementa cambios mínimos y seguros.
5. Verifica `lint`, `test`, `build`.
6. Si afecta performance, valida Lighthouse mobile + desktop.
7. Entrega diff, resultados y riesgos residuales.
